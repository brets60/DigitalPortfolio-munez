# Digital Portfolio - Jechele Ane P. Muñez

A clean, modern, human-designed personal portfolio website for **Jechele Ane P. Muñez**, a BSIT student and aspiring full-stack developer at Torres Capitol College, Inc.

---

## 🌟 Key Features

1. **Authentic, Student-Centered Design**
   - Clean, readable, and minimal aesthetic with natural typography and whitespace.
   - Professional light theme with subtle blue accents (`#2563eb`), slate typography (`#0f172a`, `#475569`), and gentle borders.
   - Avoids generic AI clichés (no neon overload, no glassmorphism abuse, no fake testimonials or exaggerated percentage bars).

2. **Live Animated Canvas Background & Ambient Glow**
   - Interactive constellation network canvas (`#live-bg-canvas`) that gently reacts to cursor movement.
   - Dual breathing ambient blue aura lights (`.ambient-glow-1`, `.ambient-glow-2`) drifting slowly in the background.
   - Automatically pauses animation when tab is inactive to preserve battery and CPU.

3. **Smooth, Subtle Animations & Micro-interactions**
   - Natural typing animation rotating through her roles and aspirations.
   - Scroll reveal animations powered by modern `IntersectionObserver`.
   - Subtle hover lifts on project cards and skill tags.
   - Pulse indicator showing real-time availability for internships and projects.

4. **Complete Portfolio Sections**
   - **Hero Section**: Personal greeting, rotating subtitle, bio, quick facts, CTAs, and Jechele's professional portrait photo.
   - **About Me**: Natural student narrative, official career objective, personal profile details (education, location, field of study, career goal), and core soft skills chips.
   - **Skills**: Categorized into *Front-End & UI*, *Backend & Programming*, and *Tools & Systems* with clean SVG icons and level tags.
   - **My Projects**: 
     - *Speed Detection and Warning System* (Hardware & Python Computer Vision)
     - *Laundry Pickup and Delivery Management System* (Full-Stack Web Application)
     - *Breta AI* (AI & Educational Language Tool)
     - Each card features an interactive "View Project" button that opens an in-depth modal overview with problem statement and key capabilities.
   - **What I've Been Learning**: 6 key learning pillars showcasing continuous technical growth and academic practical experience.
   - **Education**: Minimal timeline highlighting *Torres Capitol College, Inc.*, *Kibatang National High School*, and *Amparo Central Elementary School*, plus verified academic references.
   - **Contact ("Let's Work Together")**: Direct channels with one-click clipboard copy (`jechelemunez01@gmail.com`, `09922178120`), address, social links, and an interactive contact form with instant friendly feedback.
   - **Curriculum Vitae Modal**: Integrated printable and readable CV/Resume sheet.

## 🚀 How to Run Locally

Simply double-click `index.html` in your file explorer to open it in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

Alternatively, you can run a local server using Python:

```bash
# In the project directory:
python -m http.server 8000
```
Then navigate to: `http://localhost:8000`
